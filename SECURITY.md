# Security and confidentiality

This repository must contain only sanitized portfolio material.

Before every commit, verify that no original:
- IFC / XER / PBIX / Excel project file,
- coordinate dataset,
- contractual document,
- real activity/resource identifier,
- API key,
- personal credential,
- or executed project-data output

has been added.

If a real project file is committed accidentally, remove it from Git history rather than only deleting it in a later commit.
